# legalize-kp

将朝鲜宪制性法律文件作为 Git 仓库管理。主分支保留现行《朝鲜民主主义人民共和国社会主义宪法》；重要历史宪法作为独立分支，每一次重要制定或修订对应真实日期的 Git commit。

> 朝鲜现行宪制基础为 1972 年《朝鲜民主主义人民共和国社会主义宪法》（经 1992—2023 年多次修订）；此前为 1948 年宪法。

## 已完成

### 现行宪制基础

- **主分支**：[朝鲜民主主义人民共和国社会主义宪法](宪法/朝鲜民主主义人民共和国社会主义宪法.md) — 1972 年 12 月 27 日通过，经 1992—2023 年历次修订（主分支为最新可获全文 2023 年文本）。

### 历史分支

- [`1972宪法`](../1972宪法) — 1972 年 12 月 27 日通过（《朝鲜民主主义人民共和国社会主义宪法》）。

1948 年宪法在 `law.md` 中记录（维基文库对应文本页缺失，暂未纳入分支）。

## 构建

PowerShell（需要 PowerShell 7+，不保证兼容 Windows PowerShell 5.1）:

```powershell
.\kp\build.ps1 <目标Git仓库路径>
```

Bash:

```bash
bash kp/build.sh <目标Git仓库路径>
```

> **日期显示**：1948 年等早于 1970-01-01 的提交日期以负 Unix 时间戳写入 Git，本地 `git log` 可正确显示；GitHub 网页端无法渲染负时间戳的提交日期，会显示异常或回落到 1970。查看真实提交日期请用 `git log` 或 `git show`。维基文库抓取结果持久缓存在 `~/.cache/legalize-meta/wikisource/`。注：朝鲜历次修订的精确日期以维基文库各版页面为准。
