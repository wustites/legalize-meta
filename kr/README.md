# legalize-kr

将韩国宪制性法律文件作为 Git 仓库管理。主分支保留现行《大韩民国宪法》（第六共和国宪法）；重要历史宪法作为独立分支，每一次重要制定或修订对应真实日期的 Git commit。

> 韩国现行宪制基础为 1987 年《大韩民国宪法》（第六共和国，1988 年 2 月 25 日施行）。此前历经第一至第五共和国多次制宪。

## 已完成

### 现行宪制基础

- **主分支**：[大韩民国宪法](宪法/大韩民国宪法.md) — 1987 年 10 月 29 日公布、1988 年 2 月 25 日施行（第六共和国宪法）。

### 历史分支

- [`制宪宪法`](../制宪宪法) — 1948 年 7 月 17 日公布（第一共和国制宪宪法）。

其余各次宪法（1952/1954/1960/1962/1969/维新/1980）在 `law.md` 中记录，因维基文库对应文本页缺失暂未纳入构建分支。

## 构建

PowerShell（需要 PowerShell 7+，不保证兼容 Windows PowerShell 5.1）:

```powershell
.\kr\build.ps1 <目标Git仓库路径>
```

Bash:

```bash
bash kr/build.sh <目标Git仓库路径>
```

> **日期显示**：1948 年等早于 1970-01-01 的提交日期以负 Unix 时间戳写入 Git，本地 `git log` 可正确显示；GitHub 网页端无法渲染负时间戳的提交日期，会显示异常或回落到 1970。查看真实提交日期请用 `git log` 或 `git show`。维基文库抓取结果持久缓存在 `~/.cache/legalize-meta/wikisource/`。
