# 韩国宪制性文件整理

韩国（大韩民国）宪制基础为 1987 年《大韩民国宪法》（第六共和国）。此前历经临时政府时期与多次制宪。

## 临时政府时期（1919—1944）

大韩民国临时政府（1919—1945）时期曾颁布多部临时宪章/约法（非常设宪法），通行的文本有：
- 1919《大韩民国临时宪章》、1919《大韩民国临时宪法》、1925《大韩民国临时宪法》（第二次）、1927《大韩民国临时约宪》、1940《大韩民国临时约宪》（第三次）。
- 另有一说将 1944 年的一次修订计入（"第四次"）。此项各家说法不一，zh.wikisource 亦无对应文本页，**待核实**。

> 表中"公布"与"施行"常相隔一至两年（如 제6호 1962-12-26 公布、1963-12-17 施行；제8호 1972-12-27 公布、
> 1973-03-23 施行）。本仓库的提交日期取**施行日**，因其更能代表文本实际生效的时点。

- 现行（第六共和国）宪法：国民主权、三权分立（总统制）、宪法裁判所、总统单任制等。
- 1948 制宪宪法是第一共和国宪制基础，确立总统制、国民主权原则。

## 构建策略

- `main`：现行《大韩民国宪法》（1987，第六共和国），按 1988 年 2 月 25 日施行日期创建提交。
- `制宪宪法`：1948 年第一共和国制宪宪法历史分支。
- 其余各次宪法（1952—1980）在 zh.wikisource 对应文本页缺失（已核实 1952 年页面为 404）；可自 ko.wikisource
  `대한민국헌법 (제N호)` 获取（제1호=1948 年制宪宪法 … 제10호=现行）。本仓库暂未纳入构建分支，沿革记录于本文档。

构建脚本会按文件的制定或修订日期创建 Git commit，便于通过 `git log` 观察韩国宪制文件演变。
