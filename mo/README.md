# legalize-mo

将澳门特别行政区回归前的宪制性法律文件（《澳门组织章程》）作为 Git 仓库管理。主分支保留现行（回归前有效）文本；沿革以文件头注释与提交说明记录。

> 本仓库仅从"宪制史"角度整理文献，不涉及政治立场表述。澳门在 1999 年 12 月 20 日回归前长期适用葡萄牙宪法及海外省安排，核心宪制文件为 1976 年《澳门组织章程》（Estatuto Orgânico de Macau）；1999 年后由《中华人民共和国澳门特别行政区基本法》取代。

## 已完成

### 现行（回归前有效）宪制文件

- **主分支**：[澳门组织章程](宪制/澳门组织章程.md) — 1976 年 2 月 17 日第 1/76 号法律通过，经 1979、1990、1996 年多次修改；1999 年 12 月 20 日回归后失效。

## 构建

PowerShell（需要 PowerShell 7+，不保证兼容 Windows PowerShell 5.1）:

```powershell
.\mo\build.ps1 <目标Git仓库路径>
```

Bash:

```bash
bash mo/build.sh <目标Git仓库路径>
```

> **日期显示**：1976 年等早于 1970-01-01 的提交日期以负 Unix 时间戳写入 Git，本地 `git log` 可正确显示；GitHub 网页端无法渲染负时间戳的提交日期，会显示异常或回落到 1970。查看真实提交日期请用 `git log` 或 `git show`。注：维基文库仅提供 1996 年整合文本，主分支提交以最后一次修改日期（1996 年 7 月 29 日）为准；1976/1979/1990 各版沿革详见 `law.md`。
