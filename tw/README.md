# legalize-tw

将台湾地区宪制性法律文件（1947 年《中华民国宪法》本文及历次增修条文）作为 Git 仓库管理。主分支保留现行宪制基础；每一次重要制定或修订对应真实日期的 Git commit。

> 本仓库仅从"宪制史"角度整理文献，不涉及政治立场表述。台湾地区现行宪制框架为 1947 年《中华民国宪法》本文（未修改，部分条文经增修条文停止或冻结适用）与 1991—2005 年七次增修条文。

## 已完成

### 现行宪制基础

- **主分支**：[中华民国宪法（本文）](宪法/中华民国宪法.md) — 1946 年 12 月 25 日制宪国民大会通过、1947 年 1 月 1 日公布、同年 12 月 25 日施行；共 14 章 175 条。
- **主分支**：[中华民国宪法增修条文](宪法/中华民国宪法增修条文.md) — 1991—2005 年七次修宪，现行版本为 2005 年（民国 94 年）第七次增修条文。

### 历史分支

- [`1947宪法`](../1947宪法) — 1947 年宪法本文原始版（未含任何增修条文）。
- [`临时约法`](../临时约法) — 1912 年《中华民国临时约法》。
- [`袁记约法`](../袁记约法) — 1914 年《中华民国约法》。
- [`曹锟宪法`](../曹锟宪法) — 1923 年《中华民国宪法》（北洋政府）。
- [`训政约法`](../训政约法) — 1931 年《中华民国训政时期约法》。
- [`五五宪草`](../五五宪草) — 1936 年《中华民国宪法草案》（未施行）。

## 构建

PowerShell（需要 PowerShell 7+，不保证兼容 Windows PowerShell 5.1）:

```powershell
.\tw\build.ps1 <目标Git仓库路径>
```

Bash:

```bash
bash tw/build.sh <目标Git仓库路径>
```

> **日期显示**：1947 年等早于 1970-01-01 的提交日期以负 Unix 时间戳写入 Git，本地 `git log` 可正确显示；GitHub 网页端无法渲染负时间戳的提交日期，会显示异常或回落到 1970。查看真实提交日期请用 `git log` 或 `git show`。
